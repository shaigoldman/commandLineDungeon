Ports the complete Python dungeon RPG into `web/` with React/TypeScript, PixiJS original pixel art, a TypeScript authoritative server and persistent saves. Original Python source remains unchanged. Includes Render configuration, PostgreSQL migrations, environment documentation and an offline Android test APK.

The v0.6 update implements every requested usability/art change: swipe movement; compact player/enemy/weapon HUDs; scrolling inventory and conditional illustrated magic cards; equipment comparison before confirmation; held gear and original class walking/attack poses; poison and low-mana warnings; attack-order/damage/critical notices; thematic floors; distinctive chieftains and speech overlays. See [the complete request checklist](web/docs/FEATURES-V0.6.md).

Direct ground actions support equipping, eligible consumables, adjacent projectiles and one-use teleporters. Carried teleporters and Teleport magic escape encounters. Fractional HP no longer silently disappears on movement. Combat formulas remain covered by Python parity fixtures. Existing saves and Android signing identity are retained.

Validation: 81 TypeScript tests, six original Python tests and 80 parity fixtures; production server/browser recovery and restart; 90 mobile viewport/state combinations plus gameplay interactions; native APK build, signing and byte-for-byte bundled asset verification. Android 8+ test download is in `web/downloads/`. No physical-device testing has been performed. Render hosting requires owner credentials; exact deployment instructions are in `web/docs/DEPLOYMENT.md`.
