This adds a playable browser edition of Command Line Dungeon in `web/`, preserving the Python source. Players choose a class, explore procedural floors, fight monsters and guardians, use equipment/items/spells, trade with chiefs, level up, defeat Ruthagor, and continue into deeper floors. React/TypeScript and PixiJS provide desktop keyboard and mobile touch controls with original pixel sprites, portraits, tiles, and combat effects.

A TypeScript server owns all game actions and persists complete journeys in PostgreSQL JSONB (atomic local files for development). Private recovery keys restore saves across devices; revision checks prevent stale writes. The Render Blueprint, migration, environment documentation, deployment steps, and CI workflow are included.

Validation: 49 TypeScript tests; six original Python unit tests; 80 Python-generated parity fixtures; TypeScript engine/API/PostgreSQL tests; strict typecheck and production build; Chromium desktop/mobile smoke test including spell casting, keyboard/touch input, autosave reload, and cross-browser save recovery. Porting notes document crash fixes and browser interaction changes. Render deployment requires hosting access; no live URL is claimed.

Seeded simulations cover 840 ordinary/powered games and 181,257 actions. Fixed unearned level bonuses, nuke key loss, rounding-related deaths, inventory overflow, remote treasure prompts, NPC health bounds, and misleading combat/trade displays. `web/docs/SIMULATION.md` records reproducible commands, findings, raw aggregates, and the ordinary bot’s lack of victories without presenting powered fixtures as balance evidence.

An Android test edition packages the same game using Capacitor, with offline device saves, larger phone controls, responsive camera, Gradle source, CI build, and a verified signed APK for direct download. Web/server saves remain independent. Android package verification and offline browser checks are documented in `web/docs/ANDROID.md`; physical-device testing is pending.

Mobile gameplay now fits the viewport in portrait and landscape, with a compact health/mana HUD, map-follow/overview toggle, contextual actions, quick healing, and bottom-sheet bag/spells/log/hero panels. Native back navigation and dark system bars complete the Android layout. The updated APK preserves the existing package identity and signing certificate.

Consumable floor items can be used without a bag slot. Persistent 10%/1% health labels and frame treatments, armor-aware lethal/critical enemy-hit forecasts, movement interpolation, attack lunges/slashes, damage numbers, pickup sparkles, and energy rings make outcomes clearer. Map heroes share portrait identity details. Automated mobile checks cover 70 viewport/state combinations plus direct floor use, full-bag recovery, health thresholds, and danger warnings.

Encounters distinguish safe inspection, enemy-initiated challenges and committed combat. Enemy stats open independently, focused buttons no longer trigger the global attack shortcut, and dedicated combat items expose throwing weapons, potions, mana restoration and escape ropes. Equipment shows precise unmet Power/context requirements with disabled actions. Floor use excludes throwing weapons and ropes. Saved encounter origin and phase are optional fields, compatible with existing saves; damage, initiative and turn costs are unchanged.
