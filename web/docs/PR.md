Adds a complete playable React/TypeScript/PixiJS edition of the Python dungeon RPG in `web/`, preserving original Python source. A TypeScript server persists authoritative journeys in PostgreSQL JSONB (local atomic files for development); the offline Android package uses device Preferences. Render Blueprint, schema migration, environment documentation and CI are included.

The v0.7 Ashfall expansion adds gold, named villager shops with fixed randomized stock/prices, buyback quotes/refusals, wanted-item premiums and interlocking apocalypse stories. Killing villagers gives no rewards and instead applies a curse and a delayed ghost. New spells, items, keys/chests and border secret rooms add treasure, emperor bargains and King Niblet's half-catalog shop. See [the complete request checklist](web/docs/EXPANSION-V0.7.md).

Item inspection opens automatically and includes colored rarity and authored lore. Closing leaves the item safely. Full bags offer an atomic swap/drop chooser, including the incoming item. Weapons/staves share hand limits; comparisons remove displaced gear. Level-up overlays show current stats and changes; measured combat captions stack apart. Existing compact swipe controls, combat forecasts, held gear, original class sprites, themed floors and health/mana/poison cues remain.

Validation includes 140 TypeScript mechanics/API/database tests; six unchanged Python tests and 80 parity fixtures; deterministic playthroughs of every new mechanic; saved-game recovery/restart; 165 phone layout/state combinations across existing, expansion and combat/loot/dragon browser suites; real offline browser interactions; seeded simulations; native APK build/signature/bundled-asset/public-download verification. Android 8+ download and save boundaries are documented in `web/downloads/`. Physical-device testing remains pending. Render deployment needs owner hosting access; exact remaining steps are in `web/docs/DEPLOYMENT.md`.

Final follow-up: stats separate base, temporary effects and gear/attack-mode adjustments. Enemy views show actual crit percentages, landed hits to defeat, and the first actor. Retaliation warnings account for guaranteed kills and miss-dependent danger. Ground piles are directly selectable; item-overlay swipes leave loot and move, and stairs remain available beneath items. The original red winged serpent dragon art renders two tiles wide. Older test-release saves are unsupported.
